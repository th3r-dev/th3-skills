# Hooks and titles

## Six hook types

Write one of each, two short lines apiece (about 40 characters a line in English; Thai reads
shorter, so aim for the same visual width). Adapted from charlie947/social-media-skills'
[`hook-generator`](https://github.com/charlie947/social-media-skills/blob/main/skills/hook-generator/SKILL.md).

| Type | Line 1 | Line 2 |
|---|---|---|
| Number-led | a number from the facts | what it means |
| Contrarian | a belief the reader holds | the flip, with the reason |
| Before / after | the state before | the state after, with a number if there is one |
| Tool reference | a named tool, brand or person | what it did, or what it couldn't do |
| Admission | a mistake you made | what it cost or what you changed |
| What's next | the next piece of work | how it starts differently |

Rules:

- "I" and "ผม" only for experience the user supplied. Otherwise write the angle without the first
  person, or drop it.
- No questions as line 1 unless the question is the reader's own.
- An admission hook needs a real mistake from the facts; the banner case had three.

## Titles

Five options, each a different shape:

1. What you did and how ("Made a banner with code, checked by a script before posting")
2. A number from the facts ("3 times the bench caught my banner")
3. From X to Y ("From a GitHub README to a 1920 x 1080 Fastwork banner")
4. One input, many outputs ("One spec file, three styles")
5. The reader's frame ("Interface to Platform: a freelance banner the way a dev builds it")

Pick one as the post title. The cover takes a shorter form of it: 2 or 3 lines that each fit the
cover's text column (the renderer refuses a line that overflows).

## CTA patterns

The close is one hook and one link, in this order:

- "ถ้าอยากได้ <the result the post showed> ... หากสนใจ <one line of what you offer> จ้างผมได้ที่ <link>"
- "If you want <result> ... if you're interested, <offer>: <link>"

The CTA text names the platform the link goes to, and the landing page uses the same words.
