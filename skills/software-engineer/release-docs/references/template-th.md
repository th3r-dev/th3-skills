# Overview

vX.Y.Z พร้อมขึ้น <staging|production> มีงานที่ผู้ใช้เห็นผล N เรื่อง <งานที่รอ merge หรือขึ้นไม่ครบ ถ้ามี> มี N เรื่องรอ BA ตอบในหน้า "BA Decision"

production ยังรัน <เวอร์ชัน> ตามเลขเวอร์ชันบนหน้าจอ วันที่ DD/MM/YYYY ใบที่สถานะ <รอ deploy> จะปิดได้เมื่อ vX.Y.Z ขึ้น production แล้ว

## ต้องบอกลูกค้า

- ตัวเลขที่จะเปลี่ยนหลังขึ้น และเหตุผล
- กฎใหม่ที่ปฏิเสธสิ่งที่เคยผ่าน พร้อมจำนวนที่จะโดน แยกตามกลุ่มผู้ใช้
- งานที่ขึ้นไม่ครบ ห้ามแจ้งว่าแก้แล้ว
- ข้อจำกัดของรอบขึ้น production เช่นต้องนัดช่วงคนใช้น้อย

# BA Decision

เรื่องที่ BA ต้องตอบ แต่ละข้อมาจาก ticket หรือผลเทสซ้ำ เรียงตามข้อที่ต้องได้คำตอบก่อน

| # | เรื่อง | ทางเลือกหรือข้อเสนอ | ticket | ต้องได้คำตอบก่อน |
|-|------|--------|---|---|
| 1 | | ทางเลือกที่ ticket หรือผลเทสระบุไว้ ห้ามคิดทางเลือกเอง | KEY-104 | ขึ้น production / dev เริ่มแก้ / เปิดใช้งาน |

ใส่เฉพาะเรื่องที่ยังไม่มีคำตอบ เรื่องที่ตอบแล้วในบันทึกประชุม คอมเมนต์ใน ticket หรือผลเทส ไม่ต้องใส่
